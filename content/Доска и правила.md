Работа команды — на доске в YouGile: проект `Main`, доска `Main`.

| Колонка | Смысл |
|---------|-------|
| Backlog | Запланированное, что ещё не в работе + материалы для чтения |
| к работе | Следующее, за что берёмся |
| требует уточнение | Нужны вводные/решения — вопрос пишем в чат карточки |
| в процессе | Делается сейчас |
| тестирование | Готово, проверяем |
| готово | Завершено |

**Правила:**

- Карточка двигается по колонкам слева направо по мере готовности.
- В карточках этапов — чек-листы, отмечаем по ходу.
- Материалы (справки, эта вики) читаем до старта работ.

Доступы и безопасность — см. [[Безопасность и доступы]].
